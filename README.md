# **Welcome to Riah Johnson - Luna Project**

This repository contains my work for **Lesson 7: Understand the Web and HTML** as part of the *Intro to Programming V5* course.  

The project focuses on building a strong foundation in **web development** and **HTML**. In this repository, you'll find my `index.html` file showcasing proper HTML structure, semantic elements, and basic content for a personal portfolio page. This project demonstrates my understanding of how the web works, how HTML structures content, and how to organize a web page for readability and accessibility.

Key concepts highlighted in this repository include:

- **HTML Fundamentals**: Understanding tags, elements, and attributes to structure web content.  
- **Boilerplate Code**: Writing HTML from scratch with proper document type, meta tags, head, and body structure.  
- **Content Organization**: Creating sections for About, Experience, and Connect with headings, paragraphs, lists, and links.  
- **Web Accessibility Basics**: Structuring content to be accessible to more users.  

This repository serves as a showcase of my ability to apply foundational web development practices and organize content clearly for both users and developers.
