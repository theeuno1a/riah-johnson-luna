# **Welcome to Riah Johnson - Luna Project**

This repository contains my work for **Lesson 11: The DOM API** as part of the *Intro to Programming V5* course.  

The project focuses on **JavaScript DOM manipulation**, enabling dynamic updates to web pages based on user interactions. In this repository, you'll find my updated `index.js`, `index.css`, and `index.html` files demonstrating DOM manipulation techniques.

Key concepts highlighted in this repository include:

- **Document Object Model (DOM)**: Understanding the structure of a webpage and how to traverse it programmatically.  
- **DOM Selection and Traversal**: Using JavaScript to select and navigate HTML elements.  
- **Dynamic HTML Creation**: Creating and modifying elements like `<footer>`, `<ul>`, and `<li>` in real time.  
- **Event Handling**: Responding to user interactions on the webpage.  
- **Rendering Dynamic Content**: Populating a “Skills” section from an array of skills using JavaScript.  
- **Styling with CSS and Flex/Grid**: Organizing dynamically generated elements for responsive and accessible layouts.  
- **Automation with Date Objects**: Displaying the current year dynamically in the footer for maintainability.  
- **Accessibility Awareness**: Ensuring that dynamic content is readable and structured for all users.  

By the end of this lesson, the webpage demonstrates a **footer with the current year**, a **dynamic skills list**, and CSS-based **responsive layouts** using flexbox or grid. This project showcases the power of combining HTML, CSS, and JavaScript to create interactive and adaptable webpages.
