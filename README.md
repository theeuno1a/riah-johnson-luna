# **Welcome to Riah Johnson - Luna Project**

This repository contains my work for **Lesson 8: CSS Basics** as part of the *Intro to Programming V5* course.  

The project focuses on learning **Cascading Style Sheets (CSS)** to enhance the visual presentation of web pages created in previous lessons. In this repository, you'll find my `index.css` file alongside `index.html`, demonstrating how CSS can be used to style and layout content effectively.

Key concepts highlighted in this repository include:

- **CSS Fundamentals**: Understanding inline, internal, and external CSS, selectors, values, and units.  
- **Box Model**: Applying margins, padding, borders, and content spacing to design elements.  
- **Styling Elements**: Changing backgrounds, fonts, colors, alignment, and spacing for sections of a webpage.  
- **Classes and IDs**: Targeting specific HTML elements for custom styling.  
- **Responsive Design Foundations**: Preparing elements for future adjustments across devices.  

This repository showcases how HTML content from previous lessons can be transformed visually using CSS, demonstrating my ability to apply styling concepts creatively while maintaining organized and readable code.
