# **Welcome to Riah Johnson - Luna Project**

This repository contains my work for **Lesson 12: Asynchronous Programming and Promises** as part of the *Intro to Programming V5* course.  

The project focuses on **handling asynchronous operations in JavaScript** and integrating user interactions through forms. In this repository, you'll find updates to `index.js`, `index.css`, and `index.html` demonstrating the use of event listeners, form handling, and dynamic DOM updates.

Key concepts highlighted in this repository include:

- **Asynchronous Programming**: Understanding how non-blocking code works to improve user experiences.  
- **Promises**: Creating and handling JavaScript Promises to manage asynchronous tasks effectively.  
- **Event Handling**: Responding to user actions like form submissions with `addEventListener`.  
- **Form Handling**: Collecting user input through a structured HTML form and preventing default browser behaviors.  
- **DOM Manipulation**: Dynamically updating the webpage with submitted messages and allowing users to remove entries.  
- **Integration with HTML and CSS**: Linking JavaScript functionality to HTML forms and styling the form for usability and accessibility.  
- **Information Literacy Mindset**: Learning to assess sources of information and troubleshooting issues in asynchronous code.  

By the end of this lesson, the webpage demonstrates a **fully functional message form** with name, email, and message fields, dynamically displaying user submissions in a message list. Each message includes a **mailto link** for the sender’s email and a **remove button** to delete entries. Form fields reset after submission, and the layout is styled for accessibility and responsive design.
