# **Welcome to Riah Johnson - Luna Project**

This repository contains my work for **Lesson 5: Git Basics** as part of the *Intro to Programming V5* course. 

The project focuses on using **Git** and **GitHub** to manage code effectively, demonstrating the use of version control to track, back up, and organize files. In this repository, you'll find the foundational files for the project, including a `README.md` and an `index.html` file that serve as the starting point for practicing Git workflows.  

This project highlights the following concepts:

- **Version Control**: Understanding repositories, commits, and branching to maintain a clear history of changes.  
- **Collaborative Workflow**: Using GitHub to safely store work and manage branches for assignments.  
- **Code Organization**: Structuring files logically to support growth in coding projects.  

This repository serves as both a personal reference and a demonstration of my ability to apply fundamental programming practices, specifically focused on Git and project management techniques. It’s the starting point for building further skills in programming and software development.
