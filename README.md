# **Welcome to Riah Johnson - Luna Project**

This repository contains my work for **Lesson 9: CSS Layout** as part of the *Intro to Programming V5* course.  

The project focuses on using **CSS layout techniques**, primarily Flexbox, to create structured and visually organized web pages. In this repository, you'll find my `index.css` and `index.html` files, demonstrating layout design and formatting applied to the content from previous lessons.

Key concepts highlighted in this repository include:

- **Flexbox Layout**: Using Flexbox properties to structure sections, align items, and create responsive layouts.  
- **Navigation**: Adding a `<nav>` element with internal links to navigate between page sections.  
- **Section Organization**: Creating new sections for Skills and Projects, preparing for dynamic content in future lessons.  
- **Formatted Content**: Enhancing the layout of Experience and Connect sections using rows, columns, and Flexbox alignment.  
- **Accessibility Awareness (A11y)**: Considering how to build layouts that are accessible and easy to navigate for all users.  

This repository demonstrates how HTML content and CSS styling can work together to create an organized, user-friendly webpage while laying the foundation for dynamic updates in later lessons.
