# **Welcome to Riah Johnson - Luna Project**

This repository contains my work for **Lesson 10: Responsive Design** as part of the *Intro to Programming V5* course.  

The project focuses on creating **responsive web pages** that adapt to different screen sizes and devices using CSS techniques such as **media queries** and **CSS Grid**. In this repository, you'll find my updated `index.css` and `index.html` files showcasing these responsive design principles in action.

Key concepts highlighted in this repository include:

- **Responsive Design**: Building layouts that adapt to various device widths, from mobile phones to desktops.  
- **Media Queries**: Using CSS media queries to define styles for different screen sizes.  
- **Flexible Layouts**: Applying percentages, REMs, and EMs for scalable design.  
- **CSS Grid Introduction**: Optional layout experimentation using the CSS Grid model for more complex section formatting.  
- **Accessibility Awareness**: Ensuring the site remains usable and readable across devices and for all users.  
- **Willingness to Experiment**: Applying incremental changes and testing adjustments to refine layouts while building confidence in CSS troubleshooting.

This repository demonstrates how responsive design techniques can enhance a webpage’s usability and user experience across devices, preparing for more advanced content and layout integrations in future lessons.
