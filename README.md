# **Welcome to Riah Johnson - Luna Project**

This repository contains my work for **Lesson 13: Fetch API** as part of the *Intro to Programming V5* course.  

The project focuses on **using JavaScript Fetch API and async/await** to interact with external APIs and dynamically update a webpage. In this repository, you'll find updates to `index.js`, `index.html`, and associated CSS demonstrating API requests, error handling, and asynchronous programming.

Key concepts highlighted in this repository include:

- **Fetch API**: Making HTTP requests to external data sources from the browser.  
- **Async/Await**: Simplifying asynchronous code for readability while waiting for API responses.  
- **Error Handling**: Using `try...catch` to handle unsuccessful API requests or unexpected errors.  
- **Portfolio Integration**: Fetching a list of GitHub repositories to dynamically display on the portfolio page.  
- **Open API Project**: Practicing fetch, async/await, and DOM manipulation with an external API of choice.  
- **DOM Updates**: Dynamically rendering fetched data to the page and allowing for live user interactions.  
- **Problem-Solving Mindset**: Developing a structured approach to debugging and handling unexpected API or code issues.  

By the end of this lesson, the webpage demonstrates a **live integration of external data via Fetch API**, displaying GitHub repositories dynamically and supporting further open API exploration. The code includes proper **error handling** and **asynchronous logic** with `async/await` to ensure a smooth user experience.
